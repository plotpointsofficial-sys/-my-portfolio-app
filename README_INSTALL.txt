MY PORTFOLIO MOBILE PWA (V8)

1. IMPORTANT: In V7, select Export Backup and save the JSON file before switching.
2. Upload ALL the files in this folder (keeping icons/ folder) to an HTTPS static host such as GitHub Pages or Netlify. The published URL should serve index.html.
3. On Android Chrome, visit the HTTPS URL. Use the browser menu > Install app (or Add to Home screen).
4. Open the installed app. Choose Import Backup and select the JSON file from V7. Data does NOT migrate automatically from file:// HTML or a different website.
5. Records remain in local browser/app storage, NOT on a server. Keep regular JSON backups. Uninstalling/clearing site data may erase records.
6. Offline use works after the initial online visit and service-worker installation.
7. Live market prices and multi-device sync are NOT included.

Security: Do not enter passwords, account numbers, or other sensitive credentials. Use a trusted hosting provider and HTTPS.
